# paperline 1.4.0

- Select and copy existing PDF text naturally, without switching tools.
- Keep text selection aligned when zooming and on cropped or rotated pages.
- Open PDF links, including authenticated Moodle resources, in a new tab.
- Shorten the installed extension name and editor tab title to `paperline`.
- Use version 1.4.0 to distinguish this build from older installed copies.

The manual install build is `paperline-1.4.0.zip` (extract and load its `dist` folder). The store upload build is `paperline-1.4.0-chrome-web-store.zip` with the manifest at the archive root; it has not been published.

Verification includes native mouse selection and clipboard paste, high-DPI alignment, signed-in Moodle handoff, all editing tools, and installing the actual downloadable ZIP in Chromium.
