# Paperline 1.3.0

First packaged release of Paperline, a local PDF viewer and annotation editor for Chrome.

- Compact charcoal-and-lavender viewer with contextual text formatting.
- Editable, movable and resizable text boxes; highlight and pen tools.
- Undo/redo, duplication, keyboard nudging, and local draft recovery.
- Saved PDF annotations remain editable when reopened in Paperline.
- Automatic PDF navigation and completed-download handling.
- Same-site authenticated PDF handoff, including Moodle resource redirects and embeds.
- Setup diagnostics, site-access recovery, and automatic-opening repair.

The source repository is private. `paperline-1.3.0.zip` is the manual install build; `paperline-1.3.0-chrome-web-store.zip` is the store upload build with its manifest at the archive root.

Validation: TypeScript build, ZIP integrity/entry-point checks, dependency audit, and 25 Chromium extension end-to-end tests.
